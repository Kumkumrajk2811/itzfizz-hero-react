# Itzfizz Scroll-Driven Hero (React + Vite + Tailwind + GSAP)

## Run it
1. Install Node.js (LTS) from https://nodejs.org (one time)
2. Open THIS folder in VS Code (the one containing package.json)
3. Terminal:  npm install   then   npm run dev
4. Open the link shown (http://localhost:5173)

## Edit
- Stats / text: src/components/Hero.jsx (STATS list)
- Colours: tailwind.config.js
- Animation: src/components/Hero.jsx

## Deploy to GitHub Pages
1. Create a GitHub repo and upload ALL files of this folder (including the hidden .github folder), or push with git.
2. Repo > Settings > Pages > Source: choose "GitHub Actions".
3. Wait ~1 minute (Actions tab). Your live link appears in Settings > Pages.
